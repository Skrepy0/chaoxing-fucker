# ChaoXing Fucker

![License](https://img.shields.io/badge/license-MIT-aqua)

一个用于超星在线学习平台的用户脚本，提供 **防止切屏暂停**、**视频自动播放**、**自动静音**、**自动处理弹题**、**题目一键复制** 和 **自动切换下一节** 等功能。

> ⚠️ 本脚本仅供学习交流使用。使用者应遵守相关平台的使用条款，作者不对因使用本脚本而产生的任何后果负责，并且本脚本与其前置脚本无任何关系，前置脚本仅为个人推荐。

---

## 🧩 前置脚本

题目一键复制功能需要安装 [超星字体解密](https://greasyfork.org/zh-CN/scripts/445007-%E8%B6%85%E6%98%9F%E5%AD%97%E4%BD%93%E8%A7%A3%E5%AF%86) 脚本才会生效，否则仅会复制原本的加密文本。

## ✨ 功能特性

### 🔒 防暂停

- **鼠标离开不暂停**：拦截 `mouseout`、`mouseleave`、`blur`、`focusout` 等事件，鼠标移出播放器也不会暂停。
- **切标签不暂停**：重写 `document.hidden`、`visibilityState`、`hasFocus`，让页面始终认为自己处于前台。
- **最小化不暂停**：使用 Web Worker 定时器绕过后台标签节流，窗口最小化后仍能持续恢复播放。
- **封锁暂停调用**：重写 `HTMLMediaElement.prototype.pause` 和播放器的 `ananas.pause`，阻止超星主动暂停。
- **双通道恢复**：主线程轮询 + Worker 定时器双保险，任一通道被拦仍有另一通道兜底。

### 🔇 自动静音

- 重写 `muted` 和 `volume` 属性的 setter，页面无法恢复声音。
- 每次播放前自动静音，避免爆音。
- 静音状态下更容易通过浏览器的自动播放策略。

### ▶️ 自动播放

- 定时检测所有 `<video>` 元素，只要处于暂停且未结束状态就自动 `play()`。
- 弹题显示时暂停恢复逻辑，避免与答题流程冲突。

### 📝 自动处理弹题

- 自动检测视频播放中弹出的判断题、单选题等题目。
- 自动选择选项、点击提交、点击继续。
- 答错时自动尝试其他选项，直到答对或尝试完所有选项。
- 使用题干文本作为唯一标识记录已尝试选项，避免死循环。

### 📋 题目一键复制

- 在题目界面添加复制按钮，一键复制当前页面所有题目。
- 复制内容包含题干和选项，并自动去除选项前缀。
- **按需显示**：只有检测到题目时才会插入复制按钮；未检测到题目时不会渲染按钮，避免界面干扰。
- 需配合 **超星字体解密** 脚本使用，否则复制到的是加密文本。

### ⏭️ 自动切换下一节

- 视频播放结束后自动点击“下一节”按钮。
- 当前章节没有视频时自动继续往下跳，直到找到可播放的视频。
- 遇到“任务点未完成”弹窗时自动点击弹窗中的“下一节”越过。
- 使用 `sessionStorage` 保存状态，即使超星整页刷新也能续上跳转流程。
- 跳转上限保护：连续跳转 30 次或总时长超过 3 分钟自动停止。

### 🖱️ 跨 frame 支持

- 自动在 `document` → `window.parent.document` → `window.top.document` 中查找元素。
- 兼容超星知识点 iframe 内嵌视频、外层控制“下一节”的页面结构。

## 📦 安装方法

### Tampermonkey 浏览器扩展

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展。
2. 打开扩展的管理面板。
3. 点击“添加新脚本”。
4. 删除默认内容，将脚本代码粘贴进去。
5. 保存脚本（Ctrl + S）。
6. 点击安装按钮。

> 理论兼容 Violentmonkey 等支持 UserScript 的扩展，推荐使用 Tampermonkey。

---

## 🚀 使用说明

1. 确保已安装 Tampermonkey 扩展并启用脚本。
2. 访问超星学习平台。
3. 进入课程视频播放页面。
4. 脚本会自动开始工作，无需额外操作。
5. 视频自动静音播放，播放完成后自动进入下一节。
6. 弹出的题目会自动作答并跳过。
7. 如需使用题目复制功能，请先安装前置脚本“超星字体解密”。

按 `F12` 打开控制台，可以看到 `[chaoxing-fucker]` 前缀的运行日志，方便确认脚本是否正常工作。

## 🛠 高级操作

### 临时恢复声音

脚本默认强制静音。如需临时恢复，可在控制台执行：

```js
const p = HTMLMediaElement.prototype;
Object.defineProperty(p, "muted", p.__cfOriginalMuted);
Object.defineProperty(p, "volume", p.__cfOriginalVolume);
```
