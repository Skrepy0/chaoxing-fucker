# ChaoXing Fucker

![License](https://img.shields.io/badge/license-MIT-aqua)

一个用于超星在线学习平台的用户脚本，实现**防止切屏暂停**、**视频自动播放**、**自动静音**、**自动处理弹题**和**自动切换下一节**的功能。

## 功能特性

### 🔒 防暂停

- **鼠标离开不暂停**：拦截 `mouseout`、`mouseleave`、`blur`、`focusout` 等事件，鼠标移出播放器也不会暂停
- **切标签不暂停**：重写 `document.hidden` / `visibilityState` / `hasFocus`，让页面始终认为自己在前台
- **最小化不暂停**：使用 Web Worker 定时器绕过后台标签节流，窗口最小化后仍能持续恢复播放
- **彻底封锁暂停**：重写 `HTMLMediaElement.prototype.pause` 和播放器的 `ananas.pause`，超星无法调用暂停
- **双通道恢复**：主线程轮询 + Worker 定时器双保险，任一通道被拦仍有另一通道兜底

### 🔇 自动静音

- 重写 `muted` 和 `volume` 属性的 setter，超星无法把声音恢复
- 每次播放前自动静音，避免出现爆音
- 静音状态下的视频更容易通过浏览器的自动播放策略

### ▶️ 自动播放

- 每秒检测所有 `<video>` 元素，只要处于暂停且未结束状态就自动 `play()`
- 弹题显示时暂停恢复逻辑，避免与答题流程冲突

### 📝 自动处理弹题

- 自动检测视频播放中弹出的判断题、单选题等题目
- 自动选择选项、点击提交、点击继续
- 答错时自动换一个选项重试，直到答对为止
- 用题干文本作为唯一标识记录已尝试选项，避免死循环

### ⏭️ 自动切换下一节

- 视频播放结束后自动点击"下一节"按钮
- 当前章节没有视频时自动继续往下跳，直到找到可播放的视频
- 遇到"任务点未完成"弹窗时自动点弹窗里的"下一节"越过
- 使用 `sessionStorage` 保存状态，即使超星整页刷新也能续上跳转流程
- 跳转上限保护：连续跳 30 次或总时长超过 3 分钟自动停止

### 🖱️ 跨 frame 支持

- 自动在 `document` → `window.parent.document` → `window.top.document` 中查找元素
- 兼容超星知识点 iframe 内嵌视频、外层控制"下一节"的页面结构

## 安装方法

### Tampermonkey 浏览器扩展

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 打开扩展的管理面板
3. 点击"添加新脚本"
4. 删除默认内容，将脚本代码粘贴进去
5. 保存脚本（Ctrl+S）
6. 点击安装按钮

## 使用说明

1. 确保已安装 Tampermonkey 扩展并启用脚本
2. 访问超星学习平台
3. 进入课程视频播放页面
4. 脚本会自动开始工作，无需额外操作
5. 视频自动静音播放，播放完成后自动进入下一节
6. 弹出的题目会自动作答并跳过

按 F12 打开控制台，可以看到 `[chaoxing-fucker]` 前缀的运行日志，方便确认脚本是否正常工作。

## 高级操作

### 临时恢复声音

脚本默认强制静音，如需临时恢复，可在控制台执行：

```js
const p = HTMLMediaElement.prototype;
Object.defineProperty(p, "muted", p.__cfOriginalMuted);
Object.defineProperty(p, "volume", p.__cfOriginalVolume);
```

### 临时恢复暂停功能

```js
HTMLMediaElement.prototype.pause = HTMLMediaElement.prototype.__cfOriginalPause;
```

### 中断自动跳转

```js
sessionStorage.removeItem("cf_auto_advance_state");
```

刷新页面即可恢复默认行为。

## 注意事项

⚠️ **重要提醒**：

- **暂停按钮和音量按钮会失效**：因为 `pause()`、`muted`、`volume` 都被封锁，播放器界面上的暂停/音量按钮点了没反应。需要手动操作时请参考上面的"高级操作"
- **题目是自动作答，不是简单关闭**：脚本会尝试答题，答错会自动换选项重试，但题目本身仍会被记录
- **防止电脑进入睡眠**：浏览器整体休眠时任何脚本都无法工作，建议将电源策略设为"不睡眠"
- **多标签页会分别运行**：同时开多个超星标签页会各自消耗资源，建议只保留一个
- **跨域限制**：跨 frame 点击"下一节"依赖 iframe 与父页面同源，超星默认同源；若学校做了特殊代理导致跨域，会退回"3 秒后重试"
- **超星可能更新检测机制**：如果按钮 ID、弹题类名发生变化，脚本可能失效，需要同步修改选择器
- 请遵守平台使用规则，合理使用自动化工具
