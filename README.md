# ChaoXing Fucker
![License](https://img.shields.io/badge/license-MIT-aqua)

一个用于超星在线学习平台的用户脚本，实现视频自动播放,自动切换下一节和关闭题目弹窗的功能。

## 免责声明

本脚本仅供学习交流使用，使用者应遵守相关平台的使用条款。作者不对因使用本脚本而产生的任何后果负责。

## 功能特性

- **自动播放**：自动检测并播放视频内容
- **自动下一节**：当前视频结束后自动切换到下一节课程
- **自动关掉弹出的题目**: 自动关闭视频播放时弹出的题目(需要注意!!!)
- **音量控制**：自动静音

## 安装方法

### Tampermonkey 浏览器扩展

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 打开扩展的管理面板
3. 点击"添加新脚本"
4. 删除默认内容，将 [main.js](main.js) 中的代码粘贴进去
5. 保存脚本（Ctrl+S）
6. 点击安装按钮

## 使用说明

1. 确保已安装 Tampermonkey 扩展并启用脚本
2. 访问超星学习平台
3. 进入课程视频播放页面
4. 脚本会自动开始工作，无需额外操作
5. 视频将自动播放，播放完成后自动进入下一节

## 注意事项

⚠️ **重要提醒**：

- 本脚本仅用于自动播放视频，**不支持自动答题功能**,会自动跳过需要答题的任务
- 超星平台可能会检测自动化行为，建议合理使用
- 脚本会自动关掉弹出的题目，请使用前仔细考虑
- 请遵守平台使用规则，合理使用自动化工具
